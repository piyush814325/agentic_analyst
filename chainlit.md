# 🤖 Agentic SQL Data Analyst

**Your AI-Powered SQL Intelligence Assistant**

---

## 🎯 What This Tool Does

This is an **Agentic SQL Data Analyst** - an AI assistant that converts natural language questions into SQL queries and provides instant data insights.

### ✨ Key Features:

**1. Natural Language to SQL**
- Ask questions in plain English
- AI automatically generates correct SQL
- Self-corrects errors intelligently

**2. File Upload & Auto-Import**
- Upload CSV or XLSX files
- Automatic database table creation
- No manual schema setup needed

**3. Data Analysis & Insights**
- Get results in readable tables
- Business-focused summaries
- Support for SELECT, INSERT, UPDATE, DELETE operations

**4. Error Handling**
- Automatic SQL error detection
- Intelligent query correction
- Clear error messages when something goes wrong

---

## 🚀 How to Get Started

### Step 1: Upload Your Data
- Click the **📎 Attachment** button in the chat input
- Select a CSV or XLSX file
- The system creates a database table automatically

### Step 2: Ask Questions
- Type natural language questions about your data
- Examples:
  - "Show me top 10 sales"
  - "What are the trends in customer data?"
  - "Find records where..."

### Step 3: Get Results
- View results in formatted tables
- See the SQL query that was executed
- Get AI-generated business insights

## 🛠️ Technical Details

- **Database**: MySQL (auto-configured)
- **AI Model**: Groq LLM (llama-3.3-70b)
- **File Support**: CSV, XLSX, XLS
- **Session Timeout**: 1 hour (auto-save)
